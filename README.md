# Spam-Mail-Detection-NLP

## Overview
This project detects spam and ham messages using Natural Language Processing and Machine Learning.

## Technologies Used
- Python
- Pandas
- NLP
- TF-IDF
- Scikit-learn
- Naive Bayes

## Workflow
1. Text Cleaning
2. TF-IDF Vectorization
3. Model Training
4. Spam Prediction
